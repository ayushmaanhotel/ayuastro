Product Vision & Philosophy

AyuAstro is an AI-powered Vedic astrology platform that provides brutally honest, psychologically grounded emotional intelligence reports. Founded by Ayush UPADHYAY, the platform's tagline — "Nothing to Hide" — reflects its core philosophy: no sugarcoating, no Barnum statements, no superstition.

Core Principles

  • Deterministic Calculations: Same birth details → identical results, always. No randomness, no AI hallucination in calculations.
  • Swiss Ephemeris Accuracy: Professional-grade arc-minute level planetary positions using the same library trusted by professional astrologers worldwide.
  • Psychological Grounding: Every interpretation is anchored in planetary dignity, house placement, and classical Vedic rules — never vague fortune-telling.
  • Multi-Source Synthesis: Astrology (40%) + Numerology (20%) + Behavioral Science (40%) = holistic emotional architecture mapping.
  • AI as Synthesizer Only: AI never defines truth — it only synthesizes and articulates what the deterministic algorithms have computed.

Target Users

Spiritually curious individuals (20-40 years old, primarily Indian market) seeking self-understanding through the lens of Vedic wisdom, combined with modern psychological insight.

Swiss Ephemeris Integration

The primary calculation path uses the Swiss Ephemeris (sweph) — the same professional-grade astronomical library used by astrologers and researchers worldwide. It provides arc-minute level accuracy (vs ~1-3° error in simplified methods).

Module Architecture

// swiss-ephemeris.ts — Wrapper Module

// Lazy initialization with graceful fallback
let swephModule: typeof import('sweph') | null = null;

async function initSweph(): Promise<{ ready: boolean; error?: string }> {
  try {
    swephModule = require('sweph');
    // Test with utc_to_jd to verify module works
    const testResult = swephModule.utc_to_jd(2000, 1, 1, 12, 0, 0, 
                          swephModule.constants.SE_GREG_CAL);
    return { ready: true, version: '2.10.3' };
  } catch (err) {
    swephModule = null;
    return { ready: false, error: err.message };
  }
}

Meeus Fallback Engine

When Swiss Ephemeris is unavailable (e.g., N-API module fails to load in certain runtime environments), the system automatically falls back to simplified Meeus orbital mechanics with ~1-3° accuracy. This ensures the application never crashes due to ephemeris issues.

Planetary Longitude Formulas (Simplified)

Each planet's tropical longitude is calculated using the Meeus method:

// Sun Longitude (Meeus)
L₀ = 280.46646 + 36000.76983 × T + 0.0003032 × T²    // Mean longitude
M  = 357.52911 + 35999.05029 × T - 0.0001537 × T²    // Mean anomaly
C  = (1.914602 - 0.004817×T) × sin(M)                  // Equation of center
   + 0.019993 × sin(2M) + 0.000289 × sin(3M)
SunLongitude = L₀ + C

// Moon Longitude (Meeus)
L  = 218.3165 + 481267.8813 × T    // Mean longitude
M  = 134.9634 + 477198.8676 × T    // Mean anomaly
Ms = 357.5291 + 35999.0503 × T     // Sun's mean anomaly
D  = 297.8502 + 445267.1115 × T    // Mean elongation
F  = 93.2720 + 483202.0175 × T     // Argument of latitude
MoonLongitude = L + 6.289×sin(M) + 1.274×sin(2D-M) + ...

Retrograde Detection (Meeus)

Without Swiss Ephemeris speed data, retrograde is approximated from elongation angles:

function isPlanetRetrograde(planet, tropicalLon, sunTropicalLon) {
  const elongation = normalize(tropicalLon - sunTropicalLon);
  switch (planet) {
    case 'Mercury': return elongation < 22 || elongation > 338;
    case 'Venus':   return elongation < 10 || elongation > 350;
    case 'Mars':    return elongation > 130 && elongation < 230;
    case 'Jupiter': return elongation > 145 && elongation < 215;
    case 'Saturn':  return elongation > 150 && elongation < 210;
  }
}

Julian Day Calculation

The Julian Day Number (JDN) is the foundational time coordinate for all astronomical calculations. Two variants are used:

  • jd_et — Ephemeris Time (Terrestrial Time): Used for planet position calculations
  • jd_ut — Universal Time: Used for house cusps, ascendant, and ayanamsa

Meeus Algorithm

function dateToJulianDayMeeus(date: Date): number {
  let y = year, m = month;
  if (m <= 2) { y -= 1; m += 12; }
  const A = Math.floor(y / 100);
  const B = 2 - A + Math.floor(A / 4);
  return Math.floor(365.25 × (y + 4716)) 
       + Math.floor(30.6001 × (m + 1)) 
       + day + hour/24 + B - 1524.5;
}

// Julian centuries from J2000.0
function julianCenturies(jd: number): number {
  return (jd - 2451545.0) / 36525.0;
}

Lahiri Ayanamsa

The ayanamsa is the angular difference between the tropical (sayana) and sidereal (nirayana) zodiacs. AyuAstro uses the Lahiri (Chitrapaksha) ayanamsa — the official standard for Vedic astrology in India.

Swiss Ephemeris Method (Primary)

set_sid_mode(SE_SIDM_LAHIRI, 0, 0);
const ayanamsa = get_ayanamsa_ut(jd_ut, 0);

Meeus Fallback Formula

function calculateLahiriAyanamsaMeeus(date: Date): number {
  const T = julianCenturies(jd);
  const omega = 259.18 - 1934.14 × T;
  return 23.85394444 + 0.01396222 × (T × 100) 
       + 0.00156 × sin(omega × π/180);
}
Current Value: As of 2025, Lahiri ayanamsa ≈ 24°12' (24.2°). This means a tropical Aries at 25° becomes a sidereal Aries at ~0.8° — barely in Aries. All AyuAstro calculations use sidereal positions.

interface PlanetPosition {

  distanceAU?: number;       // Distance from Earth in AU
}

Ascendant (Lagna) Calculation

The Ascendant is the zodiac sign rising on the eastern horizon at the moment of birth. It forms the first house of the kundali and is critical for all house-based interpretations.

Swiss Ephemeris Method

const houseData = swephCalcHouses(jd_ut, latitude, longitude);
const ascTropical = houseData.ascendant;
const ascSidereal = normalize(ascTropical - ayanamsa);
const ascSignIndex = Math.floor(ascSidereal / 30);

Meeus Fallback Method

// Local Sidereal Time → Ramc → Ascendant
const gmst = 280.46061837 + 360.98564736629 × (jd - 2451545.0) + 0.000387933×T²;
const lst = normalize(gmst + longitude);
const ramc = lst × π/180;
const obliquity = (23.4393 - 0.0130 × T) × π/180;
const ascendant = atan2(cos(ramc), 
  -(sin(ramc)×cos(obliquity) + tan(latitude)×sin(obliquity)));

Whole Sign House System

AyuAstro uses the Whole Sign house system — the oldest and most traditional Vedic system. In this system, each zodiac sign equals one house, starting from the ascendant sign as House 1.

Algorithm

function calculateHouses(ascendant, planetaryPositions) {
  const houses = [];
  for (let houseNum = 1; houseNum <= 12; houseNum++) {
    const signIndex = (ascendant.signIndex + houseNum - 1) % 12;
    const sign = ZODIAC_SIGNS[signIndex];
    
    // Find planets in this house (same sign = same house in whole sign)
    const planetsInHouse = Object.entries(planetaryPositions)
      .filter(([_, pos]) => pos.signIndex === signIndex)
      .map(([name]) => name);
    
    houses.push({ houseNumber: houseNum, sign, signIndex, planets: planetsInHouse });
  }
  return houses;
}

Nakshatra Calculation

The 27 Nakshatras (lunar mansions) divide the zodiac into 27 equal segments of 13°20' each. Each nakshatra has 4 padas (quarters) of 3°20'.

// Constants
DEGREES_PER_NAKSHATRA = 360 / 27 = 13.333...  // 13°20'
DEGREES_PER_PADA = DEGREES_PER_NAKSHATRA / 4 = 3.333...  // 3°20'

// Calculate from sidereal longitude
const nakshatraIndex = Math.floor(siderealLongitude / 13.333);
const pada = Math.floor((siderealLongitude % 13.333) / 3.333) + 1;

Each nakshatra is ruled by one of the 9 planets, which determines the starting point of the Vimshottari Dasha system.

Planet-Sign Relationships

Per Brihat Parashara Hora Shastra (BPHS), a planet's relationship with a sign is determined by its relationship with the lord of that sign:

Algorithm

function getPlanetSignRelationship(planet, sign) {
  if (getSignLord(sign) === planet) return 'Own Sign';
  const signLord = getSignLord(sign);
  const relationship = getPermanentRelationship(planet, signLord);
  switch (relationship) {
    case 'Friend':       return 'Friendly';
    case 'Enemy':        return 'Enemy';
    case 'Great Friend': return 'Friendly';
    case 'Great Enemy':  return 'Enemy';
    default:             return 'Neutral';
  }
}

// For D9 (Navamsha): Divide 30° sign into 9 parts of 3°20' each
// Each part is ruled by a zodiac sign starting from Aries, Leo, or Sagittarius
// depending on the element of the natal sign

function calculateNavamsha(planetSiderealLon, natalSignElement) {
  const degreeInSign = planetSiderealLon % 30;
  const navamshaIndex = Math.floor(degreeInSign / (30/9));
  
  let startSign;
  switch (natalSignElement) {
    case 'Fire':  startSign = 0; break;  // Aries
    case 'Earth': startSign = 4; break;  // Capricorn (corrected per BPHS)
    case 'Air':   startSign = 8; break;  // Libra
    case 'Water': startSign = 8; break;  // Cancer (corrected)
  }
  return (startSign + navamshaIndex) % 12;
}
